# 怎么把 resume-warehouse 提交到 DSH 插件市场（一步一步）

## 先说一句：Fork 是什么

Fork = **把别人的仓库复制一份到你自己的 GitHub 账号下**。

你没有权限直接改 `awesome-dsh-plugin` 那个仓库，所以流程是三步：

1. 复制到自己名下（fork）
2. 在自己那份里加一个 6 行的文件
3. 申请把这份改动合并回原仓库（这就是 Pull Request / PR）

整个过程不花钱、不动对方的仓库，你复制出来的那份随时可以在 Settings 里删掉。

---

## 第一步：复制（约 30 秒，现在就能做）

1. 浏览器打开：https://github.com/awesome-dsh-plugin/awesome-dsh-plugin
2. 页面**右上角**，在 ⭐ Star、👁 Watch 按钮的右边，有一个 **Fork** 按钮（图标是两个分叉）。点它。
3. 跳到 "Create a new fork" 页面，**什么都不用改**，直接点下面绿色的 **Create fork**。
4. 等 2–3 秒，页面标题会变成 `你的用户名/awesome-dsh-plugin`，下面一行小字写
   `forked from awesome-dsh-plugin/awesome-dsh-plugin` —— 说明成功。

做完告诉我一声，我验证后把那个 YAML 文件推到你这份 fork 里。

---

## 第二步：明天点两下（2026-10-24 15:36 之后）

因为市场的 CI 要求「仓库创建满 1 天」，我们仓库建于 2026-10-23 15:35，所以 PR 最早 **10-24 15:36** 才能提。

1. 打开你自己的 fork：`https://github.com/你的用户名/awesome-dsh-plugin`
2. 页面顶部会有一条黄条 **"This branch is 1 commit ahead of awesome-dsh-plugin:main"**，
   右边有个绿色按钮 **Compare & pull request** —— 点它
3. 标题填：`Add: Bababoooi/dsh_resume_warehouse`
4. 点绿色 **Create pull request**

我明天 15:40 也会提醒你，并把分支提前推好。

## 顺带要做的：给仓库加个标签（topic）

1. 打开 https://github.com/Bababoooi/dsh_resume_warehouse
2. 右侧 **About** 区域，点小齿轮 ⚙️
3. **Topics** 输入框里输入 `dsh-plugin` 回车（可再加 `resume`、`local-first`）
4. 点 **Save changes**

---

## 要提交的文件（一共 6 行，已准备好）

- 目标路径：`data/plugins/Bababoooi__dsh_resume_warehouse--plugins-resume-warehouse.yml`
- 内容：见同目录 `entry.yml`

---

## 为什么这两件事必须你来做

我的 GitHub 连接是**细粒度 token**，它只能读写你这个仓库里的**文件内容**。
「fork 别人的仓库」和「修改仓库设置（topics）」属于更高权限，调用时返回：

```
403 Resource not accessible by personal access token
```

所以不是我没试，而是权限边界在这里。

## 备选：网页上一次性做完（今天就能）

如果你不想等，也可以：

1. 打开 https://github.com/awesome-dsh-plugin/awesome-dsh-plugin
2. 右上 **Add file** → **Create new file**
3. 它会提示你需要 fork，点那个按钮——GitHub 会自动帮你 fork 并进入编辑

5. 内容粘贴 `entry.yml` 全文
6. 底部 **Propose changes** → **Create pull request**
